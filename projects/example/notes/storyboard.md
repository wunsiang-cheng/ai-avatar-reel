# Storyboard — "I'm not a real person" (IG Reel, 9:16, 1080x1920)

Layout key:
- FULL = avatar full screen
- SPLIT = demo visual top half, avatar bottom half
- PIP = demo visual full screen, avatar in a circle at lower left (above the bottom 20% UI zone)

| # | Time (from full-greenbg.mp4) | Narration | Layout | Visual (static image + ffmpeg motion) |
|---|---|---|---|---|
| 1 | 0.0–7.0s | I'm not a real person. My face and my voice were both generated by AI. Here's the exact pipeline. | FULL | Avatar only; badge "100% AI-GENERATED" |
| 2 | 7.0–15.0s | Step one: the face. A single text prompt, sent to OpenAI's GPT Image 2.5 through the OpenRouter API. | SPLIT | Prompt text card (typewriter reveal) → crossfade to the portrait; label `openai/gpt-image-2.5-sunburst` |
| 3 | 15.0–21.0s | Step two: the voice. A short English script, spoken by a HeyGen voice model. | SPLIT | Script text card + audio waveform (ffmpeg showwavespic); label `heygen/heygen-voice-1-turbo` |
| 4 | 21.0–31.9s | Step three: HeyGen Avatar IV takes one photo plus the audio, and animates it into a lip-synced talking video. Same OpenRouter key, about five cents per second. | PIP | 21.0–28.7s: diagram card (model pill → photo + script/voice → arrow → output) with live avatar in a circle; 28.7–31.9s: INPUT still photo vs OUTPUT live avatar, pills "1 OpenRouter key" and "$0.05 / sec" |
| 5 | 31.9–36.5s | One photo, one script, one API. That's all it takes. | FULL | Avatar only; recap text "1 photo · 1 script · 1 API" |

Notes:
- Avatar portrait: output/portraits/portrait-20261029-161414-0.png (864x1536, quality=high).
- Avatar video: output/avatar/full-greenbg.mp4 (1080x1920, 25fps, 36.46s, #00FF00 background for chroma key). Its audio is the final soundtrack; word timings in output/avatar/full-greenbg.words.json.
- Avatar IV synthesized the speech itself from script/narration.txt with the HeyGen voice nadine (inline audio uploads are rejected; only public HTTPS audio URLs work).
- output/audio/narration.wav (same voice via heygen/heygen-voice-1-turbo:free) is used only as the source for the scene 3 waveform visual.
- Captions burned in for the whole video (muted viewers), grouped from word timings; product names are never split.
- Style: light minimal (warm off-white to cool gray gradient, white cards, accent #3B5BDB, Lato + DejaVu Sans Mono).
- Built by make_video.py: Pillow renders the UI layer per frame and streams it to ffmpeg, which keys the green screen, places the avatar per scene, overlays the UI and normalizes loudness to about -14 LUFS.
- Final: output/final/ai-avatar-reel.mp4 (1080x1920, 25fps, H.264 + AAC, 36.4s).
- Keep text and face out of the top 14%, bottom 20%, and right-edge icon column.
- One continuous Avatar IV clip for the full narration; layouts are cut in post.
- Optional later: AI-generated decorative b-roll if a scene feels too static.
- Add the "AI info" label when posting.

## v2 additions (AI-generated decorative footage, google/veo-3.1-lite, 720p, no audio)
- Hook 0.0–1.6s: particles assemble into the avatar (output/broll/hook.mp4, $0.12). Veo interpolates between a first frame (empty ambient background, output/broll/hook-firstframe.png) and a last frame (keyed avatar at 1.6s over the ambient background, output/broll/hook-lastframe.png, made with `make_video.py --export-hook-frame`), so the cut into the talking avatar is seamless. Source 0.4–3.4s is sped up to 1.6s and crossfades out over the last 0.2s.
- Ambient background in the FULL scenes (scenes 1 and 5): output/broll/bg-ambient.mp4 ($0.24), blurred, desaturated, ping-pong looped and blended at 45% over the gradient. SPLIT/PIP scenes keep the static gradient so the sweater feather still matches.
- Veo frame interpolation needs both first_frame and last_frame (last_frame alone is rejected; the failed job was not billed).
- No on-screen credits for the b-roll; technical details go in the post caption instead.
- Final: output/final/ai-avatar-reel-v2.mp4. `python3 make_video.py --no-ambient --no-hook` reproduces the v1 look.
