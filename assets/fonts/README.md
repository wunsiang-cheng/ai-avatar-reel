Put font files here if they are not installed on your system. The default style uses:

- Lato-Black.ttf, Lato-Heavy.ttf, Lato-Bold.ttf, Lato-Medium.ttf (https://fonts.google.com/specimen/Lato, SIL Open Font License)
- DejaVuSansMono.ttf, DejaVuSansMono-Bold.ttf (https://dejavu-fonts.github.io/)

Other fonts can be set in `[style.fonts]` in project.toml.
